# Projektregeln

- **Sauberer Neuaufbau.** Nichts aus der alten Website (kirche-cranzahl.de) oder aus
  dem Repo `website_new` übernehmen, ohne vorher nachzufragen — weder Inhalte noch Code.
- **Keine erfundenen Inhalte.** Texte, Namen, Termine, Zahlen kommen aus einer echten
  Quelle (ChurchTools, Datenbank, freigegebene Inhalte) oder aus dem Figma-Design.
- **Design** kommt ausschließlich aus der Figma-Datei „Neues Webdesign KGCranzahl",
  Seite „🎨 Design". Fehlende Seiten werden aus den Figma-Bausteinen gebaut.
- **Git/GitHub:** Arbeit auf `main` und Feature-Branches `feature/…` (nie `claude/…`).
  Commits und Pull Requests ohne Hinweise auf KI-Werkzeuge oder Co-Autoren.
- **Reihenfolge:** Datenplan → Design-System → Seiten (jeweils Design + Funktion zusammen).
- Sprache der Website und der Dokumentation: Deutsch.
